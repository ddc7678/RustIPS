# 0.3.15 — GeoIP country badges and custom colors

**Status:** implemented, awaiting approval to publish.
**Date:** 2026-11-22.

## Summary

When the GeoIP country index is loaded, RustIPS now shows the country next to
every source address:

```text
203.0.113.7 [US]
```

The default tag is **black background with white text**. Administrators can
edit that default and add per-country overrides for one or more comma-separated
ISO codes in Settings.

## Where badges appear

- Dashboard recent detections
- Dashboard top sources
- Detections table
- Logs source column
- Active blocks
- Block history
- Strikes
- Rule dry-run results
- IP-history dialog header
- Alert queue source summary

Badges are only shown when the country index is loaded and the address has a
country result. Addresses without GeoIP data render exactly as before.

## Default style

No custom entry is required. `.country-tag` overrides the detector-tag colors
with a black background and white text. The badge is uppercase and sits
immediately after the clickable IP. The default color pair is itself editable in
Settings (`settings.geo.country_default`).

## Custom colors

Settings gains a **Country badge colors** panel:

- preview of the default and every configured country;
- editable default background/text colors;
- a comma-separated country-code field (`CN, RU, KP`);
- background and text color pickers;
- Edit links that prefill the override form;
- remove an override;
- a warning when the country index is not loaded.

Storage:

```text
settings.geo.country_colors
{
  "CN": { "background": "#b91c1c", "foreground": "#ffffff" }
}
settings.geo.country_default
{ "background": "#000000", "foreground": "#ffffff" }
```

Validation:

- exactly two ASCII letters, normalized to uppercase;
- `#rrggbb` colors only, normalized to lowercase;
- invalid entries never reach the generated CSS.

## CSP-safe rendering

The UI CSP still forbids inline styles. Custom colors are emitted by a generated
stylesheet:

```text
GET /assets/country-colors.css
.country-tag { background: #000000; color: #ffffff; }
.country-CN { background: #b91c1c; color: #ffffff; }
```

The shell loads it after `app.css`, so `.country-XX` overrides the default
`.tag` colors. The route is public, contains only validated CSS and is read
from SQLite.

## Live updates

The dashboard refreshes recent detections and top sources from
`/api/summary` every two seconds. The JSON now includes a `country` field for
each recent detection and a third country element in each top-source tuple;
`app.js` renders the same badge so it does not disappear after the refresh.

## Notes

- Country names are not included in the compact index; badges show the ISO
  two-letter code.
- Custom color changes apply immediately (the CSS response is `no-store`).
- A malformed or tampered stored map is ignored by the CSS generator.
- No database schema change (v10).
- No commit or GitHub release has been made for this iteration yet.
