# 0.3.14 — disposition-rules table column sizing

**Status:** bugfix release.
**Date:** 2026-11-22.

## Problem

The Disposition rules table used automatic column widths across nine columns.
Long rule names and descriptions in the Name column were squeezed by the
Priority, Severity, State, Action, Match and timestamp columns, making the name
hard to read.

## Fix

The table now has a `rules-table` class with explicit space for the wide
columns:

```css
.rules-table { min-width: 980px; }
.rules-table th:nth-child(2),
.rules-table td:nth-child(2) {
  width: 28%;
  min-width: 260px;
  white-space: normal;
  overflow-wrap: anywhere;
}
.rules-table th:nth-child(7),
.rules-table td:nth-child(7) {
  width: 20%;
  min-width: 180px;
  white-space: normal;
}
```

The existing `.scroll` wrapper keeps the table horizontally scrollable when the
viewport is narrower than 980 px; the Name and description wrap instead of being
compressed into a narrow strip.
