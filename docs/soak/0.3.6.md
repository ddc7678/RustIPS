# Soak record — 0.3.6 release candidate

**Date:** 2026-11-21
**Host:** Debian 13 QEMU lab VM, 2 vCPU, 2 GB RAM, bridged LAN
**Service:** `rustips.service` 0.3.6, observe mode, 12 rules, geo indexes loaded

## Method

`scripts/lab/soak.sh` samples every interval:

* `MemoryCurrent`, `CPUUsageNSec`, `NRestarts` from systemd;
* SQLite DB size;
* `/metrics` packets, capture drops, stored detections, alert queue;
* `rustips status` log-event count and journal state.

It writes JSONL and checks: RSS ≤ 512 MiB, no service restarts, capture drops
≤ 1% of newly delivered packets, and a 30-day DB projection ≤ 256 MiB.

The machine-readable samples are in `0.3.6.jsonl` (120 s, DB sampled) and
`0.3.6-long.jsonl` (300 s).

## Results

| Run | Duration | Samples | RSS max | CPU | Restarts | Packets | Drops |
|---|---:|---:|---:|---:|---:|---:|---:|
| long | 300 s | 20 | 43.3 MiB | 3.27 s / 297 s (1.10% one core) | 0 | 326 | 0 |
| DB sample | 120 s | 8 | 43.5 MiB | 1.15 s / 110 s (1.05%) | 0 | 117 | 0 |

Log/journal/alert state at the end of the 120 s run:

* detections stored: 65
* log events: 6,914
* journal: running
* alert queue: 0 pending, 0 failed
* DB: 3.73 MiB
* 30-day projection from the observed growth: 0.0 MiB (the DB was flat over
  ~2 minutes; this is a short sample, not a 30-day proof)

The 90 s smoke run earlier in the cycle measured 42.4 MiB / 1.08% CPU / 0
restarts / 0 drops, consistent with the longer runs.

## Gate result

**PASS for the short lab soak** (RSS far below 512 MiB, no restarts, no capture
drops, no DB growth). This is not a substitute for the 30-day production soak
required for 1.0; it validates the sampler and the current idle/light-load
footprint.

## Notes and caveats

* The VM was idle apart from journal ingestion and one detection from the
  service restart; this is not a traffic soak. Pair it with the scorecard and
  lab acceptance runs for release validation.
* The 300 s run was taken before the DB-size sampler was given `sudo`; the
  120 s run supplied the DB figures. Both JSONL files are retained.
* `PrivateTmp`/`ProtectSystem` hardening and `UMask=0077` were active for the
  DB sample run after the unit was refreshed.
* A production soak should add synthetic traffic, alert-target failures and a
  geo update, and run for at least 30 days before 1.0.
