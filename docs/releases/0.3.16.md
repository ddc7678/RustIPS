## RustIPS 0.3.16 — Linux x86_64

Release build of RustIPS for a single internet-facing Linux host.

**Binary:** `rustips-0.3.16-linux-x86_64`
**Checksum:** `rustips-0.3.16-linux-x86_64.sha256`
**Scorecard:** `rustips-0.3.16-linux-x86_64-scorecard.json`

### Install

```sh
sha256sum -c rustips-0.3.16-linux-x86_64.sha256
sudo install -m 0755 rustips-0.3.16-linux-x86_64 /usr/local/bin/rustips
sudo rustips setup --non-interactive --install-service
sudo systemctl enable --now rustips
```

The default mode is `observe`. Set `mode = "enforce"` in
`/etc/rustips/config.toml` when nftables is available and you are ready to
block.

### Highlights

- Optional **service firewall**, disabled by default and enabled from the new
  `/firewall` page with the same state toggle used by detectors.
- Generates nftables allow rules from listening TCP/UDP services, pinned ports
  and enabled honeypot ports; established/related traffic, loopback, IPv6
  neighbour discovery and DHCP are preserved.
- The final inbound rule logs to new **DET-27 Firewall default-drop**, then
  drops or rejects. Firewall logging is rate-limited to protect the journal.
- Firewall settings apply live; schema v11 adds the shipped DET-27 alert rule
  for existing installations.
- Adds `docs/firewall.md`, `rustips check` firewall reporting, UI and nftables
  tests, and the 22-detector catalog.
