## RustIPS 0.3.14 — Linux x86_64

Release candidate build of RustIPS for a single internet-facing Linux host.

**Binary:** `rustips-0.3.14-linux-x86_64`
**Checksum:** `rustips-0.3.14-linux-x86_64.sha256`
**Scorecard:** `rustips-0.3.14-linux-x86_64-scorecard.json`

### Install

```sh
sha256sum -c rustips-0.3.14-linux-x86_64.sha256
sudo install -m 0755 rustips-0.3.14-linux-x86_64 /usr/local/bin/rustips
sudo rustips setup --non-interactive --install-service
sudo systemctl enable --now rustips
```

The default mode is `observe`. Set `mode = "enforce"` in
`/etc/rustips/config.toml` when nftables is available and you are ready to
block.

### Highlights

- 21 compiled detectors for scans, floods, HTTP probes, SSH/PAM/access logs,
  slow scans and honeypot contacts.
- Data-driven disposition rules with revisions, dry-run, GeoIP/ASN conditions
  and import/export.
- Embedded PAM-authenticated web UI on loopback, with live detections, blocks,
  strikes, allowlist, alerts and per-source history.
- nftables enforcement, observe mode and allowlist safety.
- Local SQLite evidence, webhook alert queue and resource graphs.
- MIT licensed.

### Requirements

- Linux with systemd and nftables (`apt install nftables`)
- Debian 13 or a compatible recent distribution
- Root for packet capture, nftables and PAM service installation
