## RustIPS 0.3.18 — Linux x86_64

**Binary:** `rustips-0.3.18-linux-x86_64`
**Checksum:** `rustips-0.3.18-linux-x86_64.sha256`
**Scorecard:** `rustips-0.3.18-linux-x86_64-scorecard.json`

### Install

```sh
sha256sum -c rustips-0.3.18-linux-x86_64.sha256
sudo install -m 0755 rustips-0.3.18-linux-x86_64 /usr/local/bin/rustips
sudo systemctl restart rustips
```

### Highlights

- Firewall tabs now include **Active Drops** (expiring) and **Permanent Drops**.
- System services split into **External System Services** and **Internal System
  Services** (loopback-only).
- Service tables remove the redundant Status/Mode columns; the toggle is the
  mode and new services are highlighted in yellow until acknowledged.
- Admin Drops, Honeypot port CRUD and the separate Firewall settings card are
  retained from 0.3.17.
