## RustIPS 0.3.19 — Linux x86_64

**Binary:** `rustips-0.3.19-linux-x86_64`
**Checksum:** `rustips-0.3.19-linux-x86_64.sha256`
**Scorecard:** `rustips-0.3.19-linux-x86_64-scorecard.json`

### Fix

- The Active Drops live refresh no longer pulls permanent drops into the tab.
  `/partial/blocks` now filters to expiring blocks only, matching the initial
  tab render.

Install:

```sh
sha256sum -c rustips-0.3.19-linux-x86_64.sha256
sudo install -m 0755 rustips-0.3.19-linux-x86_64 /usr/local/bin/rustips
sudo systemctl restart rustips
```
