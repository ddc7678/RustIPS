## RustIPS 0.3.17 — Linux x86_64

Release build of RustIPS for a single internet-facing Linux host.

**Binary:** `rustips-0.3.17-linux-x86_64`
**Checksum:** `rustips-0.3.17-linux-x86_64.sha256`
**Scorecard:** `rustips-0.3.17-linux-x86_64-scorecard.json`

### Install

```sh
sha256sum -c rustips-0.3.17-linux-x86_64.sha256
sudo install -m 0755 rustips-0.3.17-linux-x86_64 /usr/local/bin/rustips
sudo rustips setup --non-interactive --install-service
sudo systemctl enable --now rustips
```

The default mode is `observe`. Set `mode = "enforce"` in
`/etc/rustips/config.toml` when nftables is available and you are ready to
block.

### Highlights

- **Tabbed Firewall page:** Active Drops, Admin Drops, System Services and
  Honeypot, with firewall settings in a separate card.
- **Active blocks moved** into Active Drops; `/blocks` redirects there.
- **Admin Drops** with optional source/destination CIDR, protocol and port,
  including add/edit/delete/enable/disable.
- **System Services** default to allow, are flagged **new** until acknowledged,
  and have a per-service drop toggle that overrides the generated allow rule.
- **Honeypot** settings moved off the Settings page into its own tab, with
  add/edit/delete port controls.
- Schema v12 adds admin-rule and service-state tables. Existing databases
  migrate automatically.
